# Interface examples

Captured on 15 October 2026 from Wirkraum's existing LubaUI 0.2.0 integration,
using bundled QA sample data in an iPhone 17 Pro simulator with iOS 26.5.
Native resolution: 1206 × 2622. These images document application use of the
system, not the changes introduced in LubaUI 0.3.0 or a new App Store release.
The app's shipping dependency has not been changed by this gallery update.

Original screenshot pixels are preserved; embedded EXIF/text metadata was
removed before publication. The simulator status bar was set to 9:41.

- `results.png`: repeated cards, status badges, and a source-status warning.
- `dossier.png`: tabs, search, summary cards, and semantic status.
- `projects.png`: a bundled example project, source details, and a resume action.
- `sources.png`: alerts, information cards, and source links.
