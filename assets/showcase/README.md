# Showcase captures

Captured on 15 October 2026 from the updated LubaUI showcase, running in an
iPhone 17 Pro simulator with iOS 26.5. Native resolution: 1206 × 2622.
The showcase uses the local package with the same library sources as the
published 0.3.0 tag. The showcase improvements are on main after that tag;
checking out 0.3.0 alone does not include these new demo layouts.

- `theme-sage.png`: default palette; cards, progress, selection chips, and toggle.
- `theme-ocean.png`: the same composition with Ocean selected.
- `theme-dark.png`: the default composition in dark mode.
- `forms.png`: a compact project form using fictional example content.
- [Validation example](form-validation.png): the same form after saving and clearing its name.
- `buttons.png`: semantic button styles and base sizes. Actual targets respect configuration.
- `composition.png`: the native button expanded to reveal its detail.

Original screenshot pixels are preserved. Embedded EXIF/text metadata was
removed before publication. The simulator status bar was set to 9:41.
These are actual app captures, not rendered mockups. Screenshots do not verify
VoiceOver, contrast, or large-text behavior in every application composition.
